## 🆘 Troubleshooting

### "App won't install?"
→ Check HTTPS in URL
→ Try different browser
→ Clear cache and reload

### "Offline not working?"
→ Ensure loaded once online
→ Check Service Worker (F12)
→ Reinstall app

### "Data not saving?"
→ Enable localStorage
→ Not in private mode
→ Check storage space

### "Dark mode issues?"
→ Reload page
→ Check console (F12)
→ Clear cookies

See **INSTALL.md** for detailed troubleshooting.
