# Quick Start Guide - Teacher Portal PWA

## ⚡ 5-Minute Setup

### Step 1: Access the App
Go to your GitHub Pages URL:
```
https://jb6122999.github.io/teacher-portal-pwa/
```

### Step 2: Install on Your Device

**Android Phone (Chrome):**
1. Open link in Chrome
2. Tap menu (⋮) → "Install app"
3. Tap "Install"

**iPhone (Safari):**
1. Tap Share button (↗)
2. Tap "Add to Home Screen"
3. Tap "Add"

**Desktop (Chrome/Edge):**
1. Click install icon (⊞) in address bar
2. Click "Install"

**Windows/Mac (Standalone):**
1. Right-click on app icon
2. Create shortcut
3. Pin to taskbar/dock

### Step 3: Start Using

1. **Add Your First Class**
   - Click "My Classes"
   - Click "+ Add Class"
   - Fill in details and save

2. **Add Students**
   - Click "Students"
   - Click "+ Add Student"
   - Select the class and save

3. **Mark Attendance**
   - Click "Attendance"
   - Select class
   - Check present students
   - Click "Save Attendance"

## 💡 Common Tasks

### Create an Assignment
- Assignments → + Create Assignment
- Fill title, date, description
- Select class → Create

### Post a Notice
- Notices → + Post Notice
- Write title and message
- Post

### Set Timetable
- Timetable → + Add Time Slot
- Select day, time, class, subject
- Save

### Backup Your Data
- Settings → Export Data (JSON)
- Keep file safe

### Restore from Backup
- Settings → Import Data (JSON)
- Select your backup file
- Confirm

## ⚠️ Important Notes

- **Data is stored locally** in your browser
- **Back up regularly** using Export feature
- **Clear browser data** will delete everything
- **HTTPS required** for offline features

## 🐛 Quick Troubleshooting

**App won't load?**
- Check HTTPS in URL
- Reload page (Ctrl+Shift+R)
- Try different browser

**Data not saving?**
- Check localStorage enabled
- Not in private/incognito mode
- Check available storage

**Offline not working?**
- Loaded at least once online?
- Check browser console (F12)
- Service Worker registered?
